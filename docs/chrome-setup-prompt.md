# Claude in Chrome: set up CamCompare

Paste everything in the box below into Claude in Chrome while you're signed in
to GitHub, Vercel and the affiliate dashboards you already use (Amazon
Associates, eBay Partner Network, Impact). It works in your own browser, as
you, and never stops to ask: it does every step it can, skips any step it
can't finish or that costs money, signs an agreement or needs your tax, bank
or personal details, and ends with a numbered, step-by-step list of what's
left for you.

Public data has no database: CamCompare keeps every piece of public data
(catalog, prices, price history, photo credits) as JSON in the GitHub repo and
builds static pages from it. The one exception is private feedback from the
site's feedback form, price alerts and community accounts: they go in a few
small tables in one free Neon project, which the prompt creates. (Community
comments, reviews and threads are public but user-written, so they live there
too and load in the browser after the page.)

Generated by `npx tsx scripts/gen-setup-prompt.ts` from the retailer
registry, so every variable name matches the code.
